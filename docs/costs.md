# Costs Over Time

This page is an honest accounting of what running your classroom portal costs at
each stage of its life. The headline: **you can launch and run it for $0**, and
costs only appear if you choose to grow.

> **Scope note (please read):** this document estimates only the costs of the
> template's *intended function* — a classroom supply wish list hosted on
> Vercel's Hobby tier with the storage methods described here. Costs **outside**
> that intended function — heavy traffic beyond hobby limits, custom development,
> paid marketing, additional services you bolt on, taxes on your earnings, etc.
> — are **out of scope and not estimated here.** This same scope limitation is
> restated in [Disclosures](disclosures.md).

---

## Stage 0 — Launch and run (free)

Everything needed to get a live, working site costs nothing:

| Item | Cost | Notes |
| --- | --- | --- |
| GitHub account & repository | **Free** | Free plan is plenty. |
| Vercel hosting (Hobby tier) | **Free** *(while non-commercial)* | Generous limits for a classroom site — but the Hobby tier is for non-commercial use, so this stops being free once you're earning. See [Stage 1](#stage-1--approved-and-earning). |
| Google Sheets (or JSON file) | **Free** | Your wish list storage. |
| Amazon Associates account | **Free** | Signing up costs nothing. |
| The free `*.vercel.app` web address | **Free** | Works perfectly to share. |

**Stage 0 total: $0.** A portal that never earns commissions can happily stay
here. Once your Amazon links start earning, though, Vercel's free Hobby tier no
longer applies — see [Stage 1](#stage-1--approved-and-earning).

## Stage 1 — Approved and earning

Once your links start earning, two things may change.

### Vercel Pro may become required — this is the big one

Vercel's **Hobby** tier is for **non-commercial** use. Once your site earns
affiliate commissions, it is arguably commercial, and Vercel's terms expect you
to move to the **Pro** plan.

- **Cost:** about **$20 per month** (per member), billed by Vercel.
- **When:** once you're monetizing — i.e., earning commissions through the site.
- **Plan for it:** this is exactly what the classroom fund is meant to cover.
  Budget for it before you start actively earning. Check
  [vercel.com/pricing](https://vercel.com/pricing) for the current figure.

### Storage upgrades — only if you chose a paid method

| If you use… | Possible cost |
| --- | --- |
| Google Sheets or JSON file (recommended) | **$0** — stays free. |
| Airtable | Free tier may suffice; paid plans start around **$20/mo** if you exceed limits. |
| Supabase | Free tier may suffice; paid plans start around **$25/mo** at scale. |

If you stick with Google Sheets, there is **no storage cost** at this stage.

## Stage 2 — A custom domain (optional)

A custom web address (like `room12wishlist.org`) is a nice-to-have, not a
requirement — the free `*.vercel.app` address works fine.

| Item | Cost |
| --- | --- |
| Domain registration / renewal | typically **$10–$20 per year** |

This is a yearly cost, and the only one that exists purely for polish. See
[Procedure 9 in the Teacher's Guide](teacher-guide.md#procedure-9-reserve-a-domain-name-and-connect-it).

---

## Putting it together

| Stage | Typical recurring cost |
| --- | --- |
| **0 — Launch & run** | **$0** |
| **1 — Earning** | ~**$20/mo** Vercel Pro (+ paid storage only if you chose one) |
| **2 — Custom domain** | + ~**$10–$20/yr** |

A realistic fully-grown classroom portal runs roughly **$20/month plus ~$15/year**
— comfortably within what a modest stream of affiliate commissions can cover,
which is the whole idea behind the classroom fund.

*Prices are estimates as of 2026 and set by Amazon, Vercel, and domain
registrars — always confirm current pricing on their sites.*
